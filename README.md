# Flight Delay Analysis ✈️

A simple aviation-themed data analytics and machine learning project, created as a
portfolio piece for data analyst roles in the aerospace industry.

This project generates a synthetic flight delay dataset (AIRLINE, DEPARTURE_HOUR, DELAY)
and trains a classifier to predict whether a flight will be delayed more than 15 minutes.

## 🔧 Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn

## 🧠 What This Project Demonstrates

- Data generation and preprocessing
- Basic exploratory checks (head, describe)
- Converting a regression-style delay into a classification target (DELAYED vs NOT DELAYED)
- Training and evaluating a RandomForest classifier
- Clear, well-structured, and fully runnable code
